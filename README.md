# Catch the Stars

Hand-tracking browser game. Catch falling stars and fruit with your index finger in front of the webcam.

**Live demo:**(https://catch-the-stars1.netlify.app)

## Tech
- HTML5, CSS3, vanilla JavaScript (single file)
- MediaPipe Hands for real-time hand tracking
- Canvas 2D for rendering, getUserMedia for the camera
- Mouse and touch fallback when no camera is available

## Privacy
Video is processed in the browser. Nothing is uploaded or stored.
